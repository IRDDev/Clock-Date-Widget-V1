# Clock + Date Widget V1

A minimal desktop clock and date widget built with Python and Tkinter for Windows.

## Overview

Clock + Date Widget V1 is a simple desktop utility designed to display the current time and date in a compact window.

The project focuses on simplicity and low overhead, without unnecessary configuration menus or additional features.

## Features

- Displays the current time and date.
- Supports repositioning the widget on the desktop.
- Uses a minimal interface.
- Allows font and color customization directly in the source code.

## Built With

- Python
- Tkinter

## Getting Started

### Requirements

- Windows
- Python 3.x

Tkinter is included with most standard Windows Python installations.

### Run the Application

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run:

   ```bash
   python main.py
   ```

Replace `main.py` with the actual Python filename if it differs.

## Configuration

The widget's appearance and position can be customized directly in the source code.

There is no graphical settings interface in this version.
